
# VOYAGE — Emerald Escape 🌿

A luxury interactive travel website designed to inspire exploration, discover extraordinary destinations, and create unforgettable travel experiences.

## ✨ Features

- Interactive destination explorer
- Destination search and filtering
- Personalized destination recommendation quiz
- Interactive trip planner
- Travel cost calculator
- Wishlist for saving favorite destinations
- Destination details and image galleries
- Dark and Light mode
- Responsive navigation for desktop, tablet, and mobile
- Contact form validation
- Smooth animations and interactive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## 🎨 Design

VOYAGE features a bold emerald-inspired visual identity with cinematic travel photography, elegant typography, luxurious layouts, and a fully responsive design.

## 📱 Responsive Design

The website is optimized for:
- Desktop
- Tablet
- Mobile
